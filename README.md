## About
<sub>01 / THE PERSON BEHIND THE CODE</sub>


I'm **Noyan**, a Data Science undergraduate at **FAST-NUCES, Lahore**. I like working where software engineering meets data: building useful applications, understanding the data behind a problem, and exploring how machine learning can make a system smarter.

My recent work has been split between full-stack development, data analysis, and hands-on deep learning. I'm especially interested in computer vision and the process of turning a model experiment into a clean, reproducible pipeline.

<details>
  <summary><strong>A little more context</strong> — what I enjoy working on</summary>
  <br>

  - **Build:** database-backed applications, APIs, and practical full-stack features.
  - **Explore:** datasets, patterns, model behaviour, and the reasoning behind evaluation results.
  - **Learn:** PyTorch, CNN architectures, transfer learning, computer vision, and LLMs.
  - **Improve:** readable code, sound data models, reproducible experiments, and useful documentation.

  I enjoy debugging because it forces me to slow down, inspect assumptions, and understand what the system is actually doing.
</details>
